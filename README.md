# Laddu Learning World

An interest-led, play-based foundational learning prototype for children.

## Core interests
- Comedy / funny / harmless prank
- Family / vlog-style everyday life
- Kids / cartoon / children
- Story / horror-safe mystery / fantasy
- DIY / craft / drawing
- Music / happy birthday / dance / rhymes

## Learning
- English ABC A–Z and beginning-sound vocabulary
- Hindi स्वर + व्यंजन and picture-word association
- Counting 1–100 with quantity, sequence, comparison and patterns
- Story sequencing, prediction and problem solving
- Fine-motor/tracing and creative expression
- Rhythm, rhyme, listening and movement
- Everyday family, empathy, safety and responsibility
- Twelve future-skill strands: critical thinking, creativity, communication, collaboration, problem solving, digital literacy, information literacy, adaptability, initiative, leadership, social-emotional learning, and self-management
- NCF Foundational Stage domains are used as a design framework: physical, socio-emotional/ethical, cognitive, language & literacy, aesthetic & cultural, and positive learning habits.

## Interaction design
The interface uses glass/crystal-style controls, tactile pressed states, responsive layouts, persistent local progress, speech synthesis, and contextual Web Audio feedback. Different activity families use different sound palettes: gentle taps, success chimes, counting pulses, craft tones, music/dance beats, magic tones, and a mild spooky/mystery cue. Sound can be turned off.

## Note
This is an educational prototype informed by NCF-FS and NEP 2020 principles, not an officially certified NCF/NEP curriculum or assessment product.
