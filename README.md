# Laddu — Play & Learn

Laddu is a lightweight, mobile-first learning playground built around six child-led interests:

1. Comedy / Funny / Prank
2. Family / vlog-style stories
3. Kids / Cartoon / Children
4. Story / Mystery / Fantasy
5. DIY / Craft / Drawing
6. Music / Happy Birthday / Dance

## Learning goals
- English ABC and beginning-letter recognition
- Hindi akshar recognition and oral language
- Counting and one-to-one quantity awareness
- Sequencing, observation, memory and problem solving
- Fine-motor and pre-writing practice
- Creativity, rhythm, movement and expression

The design follows a **play-based, experiential, child-centred** approach aligned in spirit with foundational-stage priorities in India's NCF for the Foundational Stage and NEP 2020. It is not presented as an official NCF/NEP certification or curriculum product.

## Current games
- Funny Letter Prank — ABC recognition
- Family Day Story — sequencing + counting
- Cartoon Akshar Safari — Hindi akshar + oral recognition
- Mystery Number Quest — counting + observation
- DIY Drawing Studio — Hindi/English tracing + free drawing
- Birthday Dance Beat — counting + rhythm + movement

No external image assets are required; the current experience is self-contained HTML/CSS/JavaScript.
